# Plano Global

Una hipótesis macroeconómica viva: plano, eventos y posicionamiento.

Este repositorio contiene el contenido fuente y el sitio público de Plano Global.

- Sitio humano: https://facundocabrera.github.io/plano-global/
- Entrada para agentes: https://facundocabrera.github.io/plano-global/llms.txt
- Markdown consolidado: https://facundocabrera.github.io/plano-global/agent/index.md

## Estructura

- `plano.md`: tesis estructural y fases.
- `estado.md`: ubicación actual dentro del plano.
- `eventos.md`: Event Ledger.
- `posicionamiento.md`: activos preferidos, condicionales y fuera del núcleo.
- `metodologia.md`: reglas de clasificación.
- `agent/`: versiones Markdown sin presentación.
- `eventos/`: fichas trazables de acontecimientos materiales.

El contenido documenta una hipótesis en evolución. Consultá el [disclaimer](./disclaimer.md).
