# Plano Global 2025–2045+

## Tesis

Deuda soberana elevada, inflación persistente y refinanciación costosa conducen gradualmente a intervención sobre el costo del financiamiento público, tasas reales contenidas y represión financiera.

## Fases

1. Phase 1A — Monetary Break, 2023–2025.
2. Phase 1B — Geopolitical / Inflation Shock, 2025–H1 2026.
3. Phase 1C — Sovereign Fragility, H2 2026–2027.
4. Phase 2A — Intervention, aproximadamente desde 2027.
5. Phase 2B — Normalization.
6. Phase 3A — Inflation Fatigue.
7. Phase 3B — Monetary Reset.

## Criterio de Phase 2

Phase 2 comienza cuando el mercado deja de determinar libremente el costo largo del Tesoro. Puede expresarse mediante YCC, Twist, QE, buybacks, cambios regulatorios, manejo de emisión o coordinación Fed–Treasury.

Un instrumento aislado no confirma el régimen. Se requieren escala, persistencia y efecto.
